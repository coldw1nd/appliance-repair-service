# Сервис ремонта бытовой техники (КР2)

**Стек:** Java 21, JavaFX, PostgreSQL (Docker), JDBC, Apache POI, Maven.  
**Сущности:** Заявка на ремонт (`RepairRequest`) и Клиент (`Customer`).

## Запуск

1. Запустите базу данных (она создастся и заполнится тестовыми данными автоматически):
   ```bash
   docker compose up -d
   ```
2. Убедитесь, что в `src/main/resources/database.properties` порт `5434`.
3. Запустите приложение:
   ```bash
   mvn clean javafx:run
   ```

## Что реализовано

- **Архитектура:** Многослойная структура (Model, Repository, Service, FX, Util, Exception).
- **База данных:** 2 связанные таблицы с ограничениями целостности (`FOREIGN KEY`, `UNIQUE`, `CHECK`).
- **Функционал:** Полный CRUD заявок и клиентов.
- **Валидация:** Строгая бизнес-логика (проверка email, лимиты длины, стоимость 0–1 000 000, запрет даты в прошлом, правило: срочная заявка = приоритет HIGH/URGENT, контроль переходов статусов).
- **Работа с данными:** 
  - Поиск по тексту, фильтрация (статус, приоритет, срочность) и сортировка по столбцам (JavaFX `FilteredList` / `SortedList`).
  - Статистика в отдельном окне (расчёты через Stream API).
  - Экспорт отфильтрованной таблицы в Excel (интерфейс `DataExporter` + Apache POI).
- **Надёжность:** Собственные исключения (`BusinessException`, `EntityNotFoundException`) и перехват SQL-ошибок с выводом понятных сообщений пользователю.

## Остановка БД
```bash
docker-compose down      # остановить (данные сохранятся)
docker-compose down -v   # остановить и удалить данные
```

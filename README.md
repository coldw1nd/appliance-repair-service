# Сервис ремонта бытовой техники

Предметная область: Сервис ремонта бытовой техники.
Основная сущность: заявка на ремонт.
Связанные сущности: клиент и заявка на ремонт.

## Запуск

1. Установить JDK 21, Maven 3.9+ и PostgreSQL.
2. Создать БД через `src/main/resources/sql/01_create_database.sql`.
3. Подключиться к БД `appliance_repair_service`.
4. Выполнить `src/main/resources/sql/02_schema.sql`.
5. Выполнить `src/main/resources/sql/03_seed.sql`.
6. Открыть `src/main/resources/database.properties` и указать пароль PostgreSQL.
7. Запустить метод Main

## Экспорт

В пункте `6. Экспорт данных в Excel` укажите путь к файлу.

## Что реализовано

- две связанные таблицы;
- CRUD основной сущности;
- создание и просмотр клиентов;
- enum статуса и приоритета;
- бизнес-валидация;
- обработка некорректного ввода;
- JDBC, Connection, PreparedStatement, ResultSet, try-with-resources;
- поиск по неисправности, бренду и клиенту;
- фильтры по статусу и приоритету;
- сортировка по дате и стоимости через Collections/Stream API;
- статистика;
- экспорт Excel;
- интерфейс DataExporter и реализация ExcelExporter;
- собственные исключения;
- многослойная структура.
